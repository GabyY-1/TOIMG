Enregistrer un SVG animé

Cette méthode enregistre le rendu réel de l'animation dans votre navigateur. Elle fonctionne aussi pour les animations CSS qui ne se convertissent pas correctement avec un simple export PNG.

Cliquez sur « Enregistrer », puis choisissez cet onglet dans la fenêtre de partage du navigateur. L'enregistrement est local : aucune vidéo n'est envoyée à TOIMG. Le navigateur peut demander l'autorisation de partager l'écran.

Ouvrez d'abord votre fichier SVG animé dans un onglet du navigateur, puis revenez ici pour lancer la capture. Vous pouvez sélectionner cet onglet SVG lors du partage. Le format MP4 est utilisé lorsque votre navigateur sait l’enregistrer ; sinon un export WebM est proposé. Aucun fichier WebM n’est renommé artificiellement en MP4.
